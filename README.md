# Deskovky

Rodinná kolekce klasických deskových her pro Android (telefony i tablety): Piškvorky, Pexeso, Miny, Člověče nezlob se, Dáma. Plně offline, bez reklam a účtů.

- Architektura: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
